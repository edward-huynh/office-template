## Use of AI coding assistance

This project was designed and implemented with the help of an AI coding assistant (Claude Code with Claude Sonnet 5.5). The assistant proposed the architecture and wrote the code, tests and documentation in collaboration with the candidate, who made the technology and scope decisions. AI-generated code was verified by running the type checker, the Vitest suite and the Playwright suite, and by inspecting the rendered UI. Reviewers should treat the code as AI-assisted.
